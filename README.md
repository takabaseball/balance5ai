# Balance5 AI

毎日5分、未来の自分を強くする。  
**Every day, 5 minutes for a stronger tomorrow.**

## 概要
高齢者が健康寿命を延ばし、自立した生活を長く続けられるよう支援するAI健康習慣アプリのMVP。

## 機能
- 毎日5分の運動（体調に応じてメニュー自動選択）
- 健康記録（体重・血圧・服薬）とChart.jsグラフ
- 継続カレンダー
- 家族キーによるログイン
- マルチユーザー対応

## 使い方
`index.html` をブラウザで開くだけ。GitHub Pages でも動作します。

## Tech Stack
- 純粋なHTML/CSS/JavaScript（フレームワーク不使用）
- Chart.js 4.4.0 (CDN)
- データ保存：localStorage

## 今回のアップデート
- ホームに「今日のコンディション」カードを追加（運動・健康記録・服薬の達成状況を可視化）
- 時刻に応じたコーチメッセージと、現在の継続状況を強化
- マイページから記録データをJSONでバックアップ／復元
- 記録が端末内のlocalStorageに保存されることを明示
- ナビゲーション状態とスマートフォン向け視認性を改善
