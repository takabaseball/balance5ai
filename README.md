# Balance5 AI

毎日5分、未来の自分を強くする。  
**Every day, 5 minutes for a stronger tomorrow.**

## 概要
高齢者が健康寿命を延ばし、自立した生活を長く続けられるよう支援するAI健康習慣アプリ。

## 主な機能
- 毎日5分の運動（体調・睡眠・気分に応じてメニュー自動選択）
- 体重・血圧・脈拍・服薬の記録とChart.jsグラフ
- 睡眠・水分・転倒リスク・住環境の安全チェック
- 家族向け見守り設定（本人同意、3段階共有レベル、共有相手、通知方針）
- 「3日間記録なし」などの段階的な確認推奨表示
- 共有設定の変更履歴と本人向けプライバシー表示
- 音声読み上げによる今日の記録確認
- 通院用の健康記録サマリー（印刷・保存）
- 継続カレンダーとストリーク
- 家族キーによるログイン、マルチユーザー対応
- JSONバックアップ／復元

## プライバシーと安全設計
- 家族共有は初期状態でオフ
- 共有レベルは「安心確認」「生活サマリー」「詳細記録」から選択
- 本人がいつでも共有を停止可能
- 単発の変化を診断・緊急判定しない
- 通知は確認推奨という穏やかな表現を使用
- 強い症状がある場合は医療機関や地域の緊急窓口への相談を案内
- 記録はこの静的版ではブラウザのlocalStorageに保存

## 使い方
`index.html` をブラウザで開くだけ。GitHub Pagesでも動作します。

## Tech Stack
- 純粋なHTML/CSS/JavaScript（フレームワーク不使用）
- Chart.js 4.4.0（CDN）
- データ保存：localStorage
- 音声：Web Speech API（対応ブラウザのみ）

## 現在の実装範囲
本リポジトリは、家族見守り機能のUX・同意・通知設計を体験できる**静的プロトタイプ**です。別端末へのリアルタイム同期、実際のメール・プッシュ通知、認証基盤、医療機関との連携は含みません。実運用では、認証・暗号化・アクセス制御・監査ログ・同意撤回・通知基盤をサーバー側にも実装し、医療・個人情報に関する専門家レビューを行ってください。
